Bento Grid

Interactive Bento Layouts

A collection of premium, staggered, and highly responsive Bento Grid interfaces built with native CSS Grid and styled details.

How to get bento grid codes

1
Explore layouts: Scroll through the showcase and hover or interact with the items in the grids to see their animations and spotlights.
2
Open code panel: Click the "Get Code" button at the bottom of any bento layout card.
3
Select code tab: Click between HTML, CSS, JS, and React tabs to view the specific source files.
4
Copy code: Click the "Copy" button in the top-right corner to copy the snippet to your clipboard instantly.
